# Repository instructions for Codex

## Branch naming

- When creating a branch for work in this repository, use `codex/issue-<number>-<short-kebab-case-slug>`, where `<number>` is the related GitHub issue number. For example: `codex/issue-6-branch-naming`.
- If the work has no issue yet, create one before creating the branch.
- Apply this convention to new branches; existing branches do not need to be renamed.
- Follow an explicit branch name requested by the user when it differs from this convention.
